# Your private data goes here (and is never committed)

| Folder | Put here | Effect |
|--------|----------|--------|
| `chats/`  | WhatsApp "Export chat" `.txt` files, plain `.txt` (one message per line), or `.json` (a list of strings) | The doppelganger learns how you write. Only YOUR messages are kept. |
| `voice/`  | 1-5 clean recordings of you speaking (`.wav`, `.mp3`, `.flac`), 10-30 seconds each | Cloned voice (needs `requirements-voice.txt`) |
| `images/` | One clear, centered portrait photo (`.jpg`/`.png`) | Sets avatar hair / head / clothing colors. No face is ever drawn. |

Everything in these folders is git-ignored.
